# WebTransport quests

## Goal

Provide a consistent WebTransport API across native backends, browsers, and
language bindings, with reliable, interoperable streams and datagrams.

## Plan

Keep living development plans under `quest/`, ordered by priority in acts
(`a0`, `a1`, ...) as work is planned. Each quest has durable scope and completes
in one pull request; epics group related quests. Finished quests are deleted,
and git history keeps them.

Use `quest guide` for the format and workflow, and `quest check` after editing
this tree. Plan new work with `$quest-plan` in Codex or `/quest-plan` in Claude
Code; import existing GitHub issues with `$quest-import` or `/quest-import`.
